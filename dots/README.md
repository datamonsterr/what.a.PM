# Dots

Collect the dots every day; connect them when they connect.

- One file per day: `dots/YYYY/YYYY-MM-DD.md`, from [`templates/dots-entry.md`](../templates/dots-entry.md).
- Each dot: what, source (link + date), why it caught your attention.
- Connections link dots to principles (`principles.html#FP-xxx`), lessons (`content/.../research.md`) and earlier dots.
- Questions that keep coming up become planned lessons on the path.
- The `daily-dots` skill does this for you: "collect today's dots: …".
