# Labs

Standalone web apps, calculators, simulators and clickable prototypes that are bigger than a lesson game or are reused across lessons.

- One folder per tool: `labs/<kebab-name>/`, started from [`templates/web-app/`](../templates/web-app/) or the `htmx-prototype` skill.
- Each tool has a `README.md`: the question it helps answer, which lessons and principles it relates to, how to use it.
- Link a lab from a lesson with a `read` step, or embed it as a `game` step with `src: "../../../../labs/<name>/index.html"`.
