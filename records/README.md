# Records

Permanent snapshots of learning progress, exported from **Dashboard → Export progress**.

- File name: `progress-YYYY-MM-DD.json` (the dashboard names it for you). Commit one when you finish a unit, or weekly.
- Restore on a new device or browser with **Dashboard → Import**.
- Each file holds: XP per day, lessons (best score, stars, attempts), every quiz attempt with the questions missed, and per-question accuracy.
- Only your own learning data goes here: no work or customer data.
